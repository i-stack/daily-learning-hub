IOS-D001

RunLoop：事件循环与线程保活

从事件循环理解主线程为什么能持续响应，以及后台线程保活为何必须同时具备事件源与正确生命周期。

→IOS-D002

ARC：引用计数与对象生命周期

ARC 不是垃圾回收，而是编译器在编译期插入 retain/release、runtime 在运行时维护计数表的一套协作机制。本课从 extra_rc 与 SideTable 的存储结构出发，打通对象从分配到 dealloc 的完整生命周期、weak 自动置 nil 的实现、以及 ARC 留下的唯一必须由人填的坑——循环引用，并给出所有权图与 Memory Graph 验证方法。

→IOS-D003

Block：闭包、捕获与异步编程

Block 是「带捕获上下文的匿名函数」，本质是一个带 isa 的结构体——它就是一个 Objective-C 对象。本课从 Clang 编译出的三件套结构出发，讲清三种存储域的判定、捕获时到底复制了什么、__block 的 forwarding 指针如何让栈与堆指向同一份数据，以及 Block 真正难的地方：不是语法，而是逃逸之后的生命周期与执行队列契约。

→IOS-D004

Runtime：Objective-C 动态能力的根基

Runtime 把「调用哪个方法」从编译期推迟到运行期。本课从 objc_object / objc_class 的内存布局出发，打通 isa、元类、cache_t 与 objc_msgSend 的查找链路，说明 KVO、Category、Swizzling、字典转模型等上层能力共同的底层支点，并给出可复现的观察实验与工程护栏。

KVC：键值编码的查找机制：从 API、底层机制、设计取舍到工程验证建立完整理解。

→IOS-D009

Associated Object：不改变对象布局的扩展存储

Category 不能添加实例变量，因为类的 ivar layout 在编译期就已固定。Associated Object 绕开了这个限制：runtime 在对象之外用一张全局哈希表维护「宿主 → key → 值」，代价是哈希查找、全局锁和一份无法被编译器检查的隐式状态。本课讲清三层表结构、五种关联策略、为什么 key 必须是稳定地址、为什么没有 weak 策略，以及它最危险的失效形式——关联对象持有宿主形成的永久泄漏。

→IOS-D010

Method Swizzling：方法交换、AOP 与安全边界

Method Swizzling 改写 method_t 中 SEL 到 IMP 的映射，在消息查找阶段完成切面织入。本课从 objc_msgSend 链路出发，解释继承场景下 class_addMethod 的隔离作用、多个 Hook 串成的调用链风险，以及它在 AOP 方案谱系中的位置与工程护栏。

→IOS-D011

Message Forwarding：消息转发完整链路

消息转发是 objc_msgSend 查找失败后的兜底链路：先给一次动态补方法的机会，再给一次转交给别人的机会，最后才用 NSInvocation 完整转发。本课打通三阶段的触发条件、能力边界与性能代价，说明它在多播代理、AOP 与崩溃防护中的角色，以及为什么「吞掉未知消息」通常是错的选择。

→IOS-D012

NSProxy：消息代理与弱代理设计

NSProxy 是一个几乎不实现任何方法的抽象基类，消息进来直接落入转发流程，因此天生适合做代理。本课讲清它与 NSObject 子类做代理的本质差异、forwardInvocation 的必答接口与 target 消失后的返回值语义，并用它打断 NSTimer / CADisplayLink 的强引用环——同时指出一个常被误解的事实：弱代理只是让宿主有机会执行 deinit，Timer 仍然需要 invalidate。
